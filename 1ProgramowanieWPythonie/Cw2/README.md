•Stwórz dwie klasy wyjątków dziedziczące po tej klasie –NotFoundErrori AccessDeniedError.

•Dodaj obsługę kodów odpowiedzi serwera 404 i 403 by pojawienie się takich kodów rzucało odpowiedni wyjątek.
